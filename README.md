# Distribution Factory Caribbean

A pan-Caribbean trade, distribution and investment platform website.

- `frontend/` — React (CRA + craco) + Tailwind CSS site covering Home, About,
  Business Model, Clients, Doing Business, Products, Trade & Investment,
  Network (15 core markets), News & Insights, Blog and Contact.
- `backend/` — FastAPI + MongoDB service backing the site's inquiry forms
  (`POST /api/inquiries`).

## Design system

Navy (`#0F2438`), teal (`#2C6E6B`), coral (`#D9643A`), parchment (`#F1E9D8`)
and ink (`#16232E`), set in Fraunces (headlines) and IBM Plex Sans (body/UI).
